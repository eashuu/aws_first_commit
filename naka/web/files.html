Plane 03 · File & Document DLP

A pipeline that only reads Latin script has a country-sized blind spot.

The document that leaks an Aadhaar number is a photograph of a card, taken on a phone, with the holder's name printed in Devanagari. Naka runs Textract for layout and Nova Pro for the multimodal pass — because that is what these documents actually are.

The ordering rule

Tiers union. They never subtract.

This is a one-line rule with a large consequence: a later, cleverer model may only ever add findings to what an earlier tier proved.

1

Local, deterministic, and final

An Aadhaar number that passes the Verhoeff checksum is an Aadhaar number. No model gets a vote on that. Tier 1 runs first, on-device where there is a device, and its findings cannot be removed downstream.

2

Layout and standard entities

Textract for document structure, Comprehend for the entity classes where a regex is guesswork — names, addresses, dates. Added to tier 1's set.

3

The multimodal pass

Nova Pro reads the image itself, including Indic scripts. This is the tier that catches the identity card nobody transcribed — and it is purely additive, so a bad day for the model degrades coverage without ever clearing a document.

If a tier cannot run, the document is not clean — it is unscanned. The audit row records which tiers ran and which did not, and the console reports a gated service as a neutral NOT_RUN rather than a green tick. The failure this product exists to prevent is a blind spot wearing the clean state's clothes.
Shared state

A file's findings spend the same budget

A document is not a separate world. What a scan discloses about a subject is charged to that subject's ledger, exactly as a tool call would be.

One ledger, three planes

An agent that has already learned three fields about a subject cannot then be handed a document containing the fourth. The budget does not reset because the data arrived in a different format.

Placeholders survive the format

A masked entity in a document becomes the same numbered placeholder it would in a JSON field — so the model can carry it, compare it and hand it back into a tool call, where Q3 decides whether it may be restored.

Types and counts only

The audit row says a PAN was found and withheld. It does not and cannot say which PAN — there is no field on the API that could carry one, which is why a scan result is safe to keep.

Check what's actually reachable.

The console probes Textract, Comprehend and Nova Pro live against the account and reports what it finds — including when the answer is "not entitled".
